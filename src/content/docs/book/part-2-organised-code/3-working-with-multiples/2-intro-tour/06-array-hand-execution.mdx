See how to use our hand-execution process when working with arrays.

There are many different ways to hand-execute/trace a program. We are wanting you to use this to show the steps the the computer performs.

You may encounter other approaches to do this which are usually focused on understanding algorithms, so they tend to focus on showing the state of the algorithm within these steps. These versions will be more appropriate in later studies, so for now we want you to focus on what the code is doing.
