For this chapter, focus on building the linked list. You can then 

Create methods on the linked to do the following:

- `insert_after` to add a node after a given node. Think about what happens if you insert after the last node of the list.
- `insert_before` to add a node before a given node. Think about what happens if you insert before the first node of the list.
- `prepend` to add a value to the start of the linked list.

Working on the maze should also be fun if you have time.
